# Plan: render modes and panel (group 3)

Base: `zig-slang` with the renderer core merged. Four packets in parallel,
branches `zs-pt`, `zs-rm`, `zs-mlp`, `zs-ui`. Merge order: pt, rm, mlp, ui.

## Mode-plugin contract (from the renderer core)

- Zig: a struct in `src/render/` with one variant in `Renderer.ModeKind` and
  `Renderer.Mode`; comptime-checked signatures:
  `pub const display_contrast: f32`; `init(gpa, shared: *const Renderer.Shared) !Self`;
  `deinit(*Self, gpa)`; `record(*Self, gpu.CommandList, *const Renderer.Shared, *const Renderer.Frame) gpu.Error!void`;
  `invalidate(*Self, *const uniforms.SceneUniforms) void` (after init and on
  preset change; bakes go stale here and rerun inside the next `record`).
- `Shared = { device, luts: GpuLuts }` (cie, srgb_to_spectrum, ozone buffers;
  camera_responses texture; linear_clamp, linear_repeat_u samplers), with a slot
  for Earth maps. `Frame = { uniforms, scene, accum }`.
- `record` adds one sample per pixel, records only, never reads back.
- Slang: mode kernels `import shared.bindings;` (frame, scene, accum, LUT
  buffers, samplers), `[numthreads(MODE_GROUP_SIZE, MODE_GROUP_SIZE, 1)]`,
  `PixelSample s = PixelSample(thread.xy); if (!s.valid) return;
  s.camera_ray_direction(); s.rng.next4(); s.accumulate(rec709);`.
- Host: `ModeKernel.init(device, "modes/x", "x_main")` and
  `kernel.dispatch(cmd, shared, frame, &.{ mode bindings })`; extra kernels are
  plain `gpu.Kernel`s on the same command list. Example: `src/render/DebugMode.zig`.

## Surface interface (`shaders/earth/surface.slang`)

`intersect_surface`, `surface_visible`, `offset_surface_point`,
`sample_surface -> SurfaceSample{normal, albedo_srgb, ocean, bathymetry,
emissive}`. Committed as a sphere-only implementation honoring
`scene.surface.x` albedo. The path-tracer packet replaces the bodies with the
heightfield and the Earth maps (keeping the signatures); the ray marcher calls
only these functions for the surface.

## Packets

- **pt: path tracer + Earth maps.** GPU upload of `assets.EarthMaps` through
  `TilePlan` into `Texture2DArray`s (Shared slot; quality from config, fallback
  to Q1 when Q2 exceeds limits or memory), `shared/earth_bindings.slang`
  globals + tiled sampling, `ModeKernel` binding Earth-map globals when a
  kernel declares them, heightfield sphere tracing with manual f32 bilinear
  topography, surface.slang bodies, `modes/pathtrace.slang` covering both
  presets (clouds, night lights, stars, sun disk, NEE, delta/ratio tracking,
  canonicalization for `symmetric`), plus a public single-wavelength
  `path_radiance` function for data generation. Parity renders vs Taichi CPU.
- **rm: ray marcher.** GPU LUT bakes (transmittance 64x64x441 texel-centred;
  multiple scattering 32x32x441 Hillaire closed form) in `invalidate`/`record`,
  `modes/raymarch.slang` per the spec with fixes, surface via surface.slang.
- **mlp: MLP mode.** Weight upload, `modes/mlp.slang` forward pass (exact GELU
  via erf approximation), uvwz from the camera ray, scale constant for weights
  trained on the unnormalized pdf. Then `earth datagen` once `path_radiance`
  lands.
- **ui: panel and finishing.** Full ImGui panel (mode, preset, texture quality,
  sun, FOV, aspect, exposure, CRF with names, gamma, spp and timing readout),
  screenshots (P, PNG via assets.Image), `presets/*.zon` converted from
  `config - *.txt`, `--data <dir>` asset root (LUT/, textures/, cache/),
  move the camera `View` type out of `viewer/` into `render/`.
